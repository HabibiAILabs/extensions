# Habibi

Searchable local documentation for Habibi's runtime and extension APIs.

The `habibi-docs.search` tool is selected through the ordinary semantic tool index. It returns focused sections covering events, context, tools, KV, web routes, capabilities, security, and extension installation. The complete guide is not added to every invocation.

This extension does not modify packages itself. An installed coding or workspace extension can use the returned documentation while editing extension source.
